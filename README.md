# ML-Heart-Disease
This project uses machine learning to predict heart disease based on patient health data. It involves data preprocessing, exploratory analysis, model training, and evaluation to identify key risk factors and improve early diagnosis.

Implemented Features
✅ Data Preprocessing – Cleans and prepares the dataset by handling missing values, encoding categorical variables, and normalizing numerical features.

✅ Exploratory Data Analysis (EDA) – Identifies patterns, correlations, and key risk factors using statistical analysis and visualizations.

✅ Dendrogram for Clustering – Uses hierarchical clustering and dendrograms to analyze relationships between features and detect hidden patterns in the dataset.

✅ Machine Learning Models – Implements multiple models (Logistic Regression, Random Forest, SVM, etc.) to predict heart disease and compare performance.

✅ Feature Selection – Identifies the most important medical factors influencing heart disease risk to improve model accuracy.

✅ Model Evaluation – Uses accuracy, precision, recall, F1-score, and ROC-AUC to assess performance and optimize predictions.
